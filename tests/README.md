# RouterOS execution checks

Requirements: Python 3 with `pexpect`, `qemu-system-x86_64`, and a fresh official RouterOS 7.25 CHR raw image.

```sh
python tests/chr_smoke.py /path/to/chr-7.25.img
```

QEMU uses a temporary snapshot. The source image is not modified. A temporary script copy uses a test WAN interface, two test domains, and a local HTTP mock API. Cloudflare credentials are not required.

Manual execution uses the `admin` account and `use-script-permissions` with `read,write,policy,test`. Coverage includes source parsing, initial synchronization, disabled-address exclusion, unchanged IP, partial and total failures, HTTP error logging, WAN reversion, TestMode, proxy payloads, and overlapping runs.

Scheduled execution uses `on-event=cloudflare-ddns` with a 10-second interval. Coverage includes the first execution delay, initial DNS changes from `1.1.1.1`, cache persistence, unchanged-IP skips, invalidation of an existing cache after partial failure, and automatic retry on the following run.

Permission checks exclude `read`, `write`, `policy`, and `test` individually from both the script and scheduler. They verify configuration and Fetch permission errors, cache loss, and repeated updates. An additional check uses script policy `read,test` and scheduler policy `read,write,policy,test` to verify permission inheritance.

Job completion checks use a 30-second limit. Error assertions inspect only script logs generated by the current test. Cache checks read the script environment without creating or assigning global variables.

TLS certificate validation, live Cloudflare integration, and physical-router behavior are outside the test scope. The console log path is printed at startup.
